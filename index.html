Coding Agents for Generalized Task and Motion Planning Problems

We study whether coding agents can develop reusable programs for manipulation tasks across 28 simulated environments.

Generalized task and motion planning

Task and motion planning (TAMP) combines decisions about what a robot should do—such as which object to move—with decisions about how it can move while satisfying geometric and physical constraints.

Generalized TAMP seeks a reusable policy for a family of problems. The task stays the same, while the number of objects, their positions, and other instance details change. In this study, the policy is a program written by a coding agent, which we call AgenticGenPlan.

Experimental setup

Program synthesis

The coding agent receives a task description, a simulator API, and a $20 synthesis budget. It can run experiments and revise its program. In the main setting, it receives neither the simulator source nor hand-designed planning abstractions. The + source setting additionally provides the simulator source code.

Held-out evaluation

We freeze each program and evaluate it on 100 unseen instances, with five independent synthesis runs per method and environment. The program selects actions without further LLM calls. Environments provide fully observed, object-centric states; visual perception is outside the scope of this study.
